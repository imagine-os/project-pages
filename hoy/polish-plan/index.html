Hoy UI Polish Plan
HoyOS · UI polish · kickoff

Between Gigs builds it.
Hoy dresses it.

The plan for polishing HoyOS: take the component structure, roles and rules from the Between Gigs design system, keep every colour, typeface and material from Hoy, and add the cosmetic layer in stages.

Audited build v0.25.0 imagine-os.github.io/hoy 22 Oct 2026 · 8 days to MVP launch (Oct 30) Owner: Anowar (UI polish)
The model

Two layers, kept apart

Structure · from Between Gigs

What things are and how they behave

  • The 55 components and their variants, states and props
  • Semantic token names (bg, surface, ink, action, line…)
  • Rules: one primary action per view, one tab style, fixed status words
  • Spacing on a 4px base, radius roles, z-index ladder, focus ring
  • Accessibility bar: 4.5:1 text, 3:1 controls, status never colour alone
Skin · from Hoy

How it looks and feels

  • River blues, sand and cream, the sun-yellow highlight
  • Cormorant Garamond for moments, DM Sans for the interface
  • Stone and carved shadows, linen and paper textures
  • Arch shapes, the slow 7s "breath", the "Todo empieza HOY" voice
  • Seven nature tones (moss, river, clay, sun, sage, slate, plum)

The rule that keeps this clean: components only ever read Between Gigs names; those names resolve to Hoy values. Changing the brand never means touching a component.

Where the cosmetics go

Three surface tiers

Between Gigs says "calm workspace, loud moments". For Hoy that becomes a dial per surface. Staff work fast and need quiet screens; members and the public should feel the studio.

Calm

Staff and admin

Flat surfaces, hairlines, light shadows. Hoy colour and type only. No textures behind data.

Type follows the same idea. Between Gigs has four roles: display, sans, serif, mono. For Hoy: display = Cormorant Garamond (heroes, greetings, big moments), sans = DM Sans (all interface text, including app page titles, replacing Inter), serif = Cormorant for manual and long reading, mono = JetBrains Mono for times, IDs and money columns. Radius: controls 12px, cards 16px, panels 24px, pills full. Arches stay as a Hoy-only shape for imagery.

Audit · v0.25.0

What I found on the live build

Checked at a desktop width of about 800px in the light theme. Data mismatches already in Demo Findings (HALL-1 to HALL-16) are left out unless they affect the UI.

Fix now/site

The public site scrolls sideways and shows dev controls

A horizontal scrollbar appears at 800px. The nav carries a "Latest · Actual" version picker. The logo slot rendered empty above a small "HUMAN CLUB" line (relates to HALL-8). Fix: find the overflowing element, move the version picker to the dev bar, use the HOY wordmark.

Fix now/admin

KPI values are cut off

"Ingresos 30 días" reads "$ 8.020.0…". Fix: Stat component with compact money format and a smaller size step instead of an ellipsis.

Fix now/admin

Class times break over two lines

"Hoy en un vistazo" shows "7:10 a." then "m." on the next line. Fix: times in mono with white-space: nowrap and a non-breaking space before "a. m.".

Fix now/staff/checkin

Labels clip in the busiest staff screen

The class picker ends at "(9/1(", the class chips cut "Pilates Upper Body", and the search placeholder is cut. Fix: Combobox with full option text, chips that wrap to two lines, a shorter placeholder ("Buscar").

Polish/app

The sun yellow is used as a banner

"Aún no tienes paquete" sits on a full yellow band. In the system, yellow is for markers and celebrations. Fix: info Banner; save the yellow for "Todo empieza HOY" and booking-confirmed moments.

Polish/admin/*

Every card carries the heaviest shadow

Dense admin screens stack the multi-layer stone shadow on every block, so nothing stands out. Fix: calm tier uses surface, line and a small shadow. Stone stays for the member app and site.

Polish/admin/crm

Two tab styles and a hidden column

The segment filters are pills and the last column header is cut to "V". Fix: underline Tabs with counts, a sticky first column, and the table scrolling inside its own frame.

PolishAll shells

Testing tools sit in the product chrome

"Wireframe", "Modo dev", the version badge and the demo user picker share the top bar with real controls (relates to HALL-16). Fix: one thin dev bar that the production build leaves out.

BrandHub, app, site

Titles change typeface from surface to surface

The site uses Cormorant, the hub and apps use Inter, and body text is DM Sans. Fix: the type roles above. Drop Inter.
