How it lands in HoyOS

Rules
  1. One blue hero and one sun action per screen; everything else sits on paper.
  2. Class tones fill whole tiles (stats, a person's profile) with deep ink text; never pale tints behind small text.
  3. Serif for names and titles (pages, tiles, classes, people); sans for every number, label and control.
  4. Status is a dot + word pill, readable in both themes.
  5. Rounded everything: 2rem tiles, 1.5rem cards, pill controls.
Build order
  1. Studio Pulso tokens scoped to the staff shell (.deskshell), so the member app and website are untouched.
  2. Shared components in that scope: Button, Input, Chip, Badge, Tabs, StatTile, Card, ClassRow, Notice, Toast, EmptyState, DataTable, Drawer, Avatar.
  3. DesktopShell: the river sidebar tile, sun active pill, serif page title, paper top controls.
  4. Checks: contrast ≥ 4.5:1 light and dark, spacing lint, ES/EN screenshots.
A visual reference for review; nothing is built yet. People, classes and amounts are fictional HoyOS seed data.
